This is the first post on **ugu-logs** — a place where I write about AI topics I'm
digging into and projects I'm building.

Expect posts on things like:

- Notes on papers and techniques I'm learning
- Write-ups of side projects as I build them
- Practical lessons from getting things to actually work

The site itself is intentionally simple: static markdown files, rendered with
[Astro](https://astro.build), hosted for free on GitHub Pages. No database, no
build server, no accounts — just write a markdown file and push.
